# 🎮 Hangman Game

A colorful and interactive **Hangman Game built with Python and Tkinter**.

The player has to guess the hidden word one letter at a time. The game provides a graphical interface with a Hangman display, attempts counter, letters-left counter, guessed letters, and game controls.

## ✨ Features

* 🎮 Interactive Tkinter GUI
* 📝 Random word selection
* 🔤 Letter-by-letter guessing
* ❤️ Attempts Left counter
* 🔤 Letters Left counter
* 📋 Guessed Letters display
* ✅ Correct and wrong guess messages
* 🎉 Winning message
* 💀 Game Over message
* 🔄 Play Again button
* 🛑 Stop Game button
* ⌨️ Press Enter to submit a guess
* 🎨 Colorful dark-themed interface

## 🛠️ Technologies Used

* 🐍 Python
* 🖼️ Tkinter
* 🎲 Random module

## 🎯 How to Play

1. A random word is selected.
2. The hidden word is displayed using underscores.
3. Enter one letter in the input box.
4. Click **GUESS** or press **Enter**.
5. If the letter is correct, it appears in the word.
6. If the letter is wrong, one attempt is lost.
7. Continue guessing until you reveal the complete word.
8. Click **PLAY AGAIN** to start a new game.
9. Click **STOP GAME** whenever you want to stop.
